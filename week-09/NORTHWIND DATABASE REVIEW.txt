NORTHWIND DATABASE REVIEW

TABLE: Categories

What does a value in this column represent? What values might you see here?
- CategoryID: Unique numeric ID for each category, values 1-8
- CategoryName: Category name e.g. Beverages, Seafood, Produce
- Description: Long text description of the category
- Picture: Binary image data

Is this column a part of the primary key to this table?
- CategoryID: YES
- CategoryName: NO
- Description: NO
- Picture: NO

Is this column a part of a foreign key that points to a record in another table?
- CategoryID: NO (but appears as FK in Products table)
- CategoryName: NO
- Description: NO
- Picture: NO

Would this column be valuable to bring into our Power BI Model?
- CategoryID: YES - needed for table relationship with Products
- CategoryName: YES - used for grouping in reports
- Description: NO - long text, not useful for analysis
- Picture: NO - binary data, not usable in Power BI

Do you believe this column is appropriately named for Data Analysis purposes?
- CategoryID: YES
- CategoryName: NO - rename to Category


What might be the data type and format for this column in a Power BI Model?
- CategoryID: Whole Number
- CategoryName: Text

Can you think of any calculations where this column data might be used?
- CategoryID: Table relationships only
- CategoryName: Sales by category, count of products per category

TABLE: Employees
-----------------

- City: YES - geographic analysis
- Region: YES - geographic analysis
- PostalCode: YES - geographic analysis
- Country: YES - geographic analysis
- HomePhone: NO - contact info
- Extension: NO - contact info
- Photo: NO - binary data
- Notes: NO - long text
- ReportsTo: YES - org chart / hierarchy
- PhotoPath: NO - file path, not useful

Do you believe this column is appropriately named for Data Analysis purposes?
- EmployeeID: YES
- LastName: NO - rename to Employee Last Name
- FirstName: NO - rename to Employee First Name
- Title: NO - rename to Employee Title
- TitleOfCourtesy: NO - rename to Employee Title Of Courtesy
- BirthDate: NO - rename to Employee Birth Date
- HireDate: NO - rename to Employee Hire Date
- City: NO - rename to Employee City
- Region: NO - rename to Employee Region
- PostalCode: NO - rename to Employee Postal Code
- Country: NO - rename to Employee Country
- ReportsTo: NO - rename to EmployeeReportsToEmployeeID

What might be the data type and format for this column in a Power BI Model?

- LastName/FirstName/Title/TitleOfCourtesy: Text

- ProductID: YES - references Products.ProductID
- UnitPrice: NO
- Quantity: NO
- Discount: NO

Would this column be valuable to bring into our Power BI Model?

- ProductID: YES - needed for relationships
- UnitPrice: YES - core sales metric
- Quantity: YES - core sales metric
- Discount: YES - discount analysis

Do you believe this column is appropriately named for Data Analysis purposes?
- OrderID: YES
- ProductID: YES
- UnitPrice: NO - rename to Unit Price
- Quantity: NO - rename to Sales Quantity
- Discount: NO - rename to Sales Discount Percent

What might be the data type and format for this column in a Power BI Model?
- OrderID: Whole Number
- ProductID: Whole Number
- UnitPrice: Fixed Decimal (Currency)
- Quantity: Whole Number
- Discount: Percentage

Can you think of any calculations where this column data might be used?
- Sales Amount = Quantity * UnitPrice * (1 - Discount)
- Discount Amount = Quantity * UnitPrice * Discount
- Total units sold = SUM(Quantity)

TABLE: Products
----------------
What does a value in this column represent? What values might you see here?
- ProductID: Unique numeric ID 
- ProductName: Product name 
- SupplierID: ID of the supplier 
- CategoryID: ID of the category 
- QuantityPerUnit: Packaging description 
- UnitPrice: Current listed price 
- UnitsInStock: Current inventory

- All others: NO

Would this column be valuable to bring into our Power BI Model?
- ProductID: YES - needed for relationships
- ProductName: YES - product analysis
- SupplierID: YES - needed for relationship with Suppliers
- CategoryID: YES - needed for relationship with Categories
- QuantityPerUnit: NO - free text, not useful for analysis
- UnitPrice: YES - current price analysis
- UnitsInStock: YES - inventory analysis
- UnitsOnOrder: YES - incoming inventory analysis
- ReorderLevel: YES - low stock alerts
- Discontinued: YES - filter active vs discontinued

Do you believe this column is appropriately named for Data Analysis purposes?
- ProductID: YES
- ProductName: NO - rename to Product
- SupplierID: YES
- CategoryID: YES
- UnitPrice: NO - rename to Product Current Unit Price
- UnitsInStock: NO - rename to Product Units In Stock
- UnitsOnOrder: NO - rename to Product Units On Order
- ReorderLevel: NO - rename to Product Reorder Level
- Discontinued: NO - rename to Product Discontinued

What might be the data type and format for this column in a Power BI Model?
- ProductID/SupplierID/CategoryID: Whole Number
- ProductName: Text
- UnitPrice: Fixed Decimal (Currency)
- UnitsInStock/UnitsOnOrder/ReorderLevel: Whole Number
- Discontinued: True/False

Can you think of any calculations where this column data might be used?
- UnitsInStock vs ReorderLevel: Low stock alert flag
- UnitsInStock + UnitsOnOrder: Total available inventory
- UnitPrice vs Order Details UnitPrice: Price change over time
- Discontinued: Count of active vs discontinued products
